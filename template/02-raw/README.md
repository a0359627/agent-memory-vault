# 02-raw — 不可變來源

這一層只放**原文**：貼上的文字、逐字稿、外部 repo 的抓取版本、轉檔出來的可搜尋版本。
規則只有一條：**原文不編輯**。結論、取捨與現行判斷一律寫在 `03-wiki/`，不要在這裡下結論。

一個來源一個資料夾：`02-raw/<主題>/`，裡面放原文與一張出處卡 `SOURCE.md`。

## 出處卡欄位（`02-raw/<主題>/SOURCE.md`）

```markdown
---
title: RAW — <這批原文是什麼>
type: raw-source
captured: YYYY-MM-DD
immutable: true
---

# RAW：<來源名稱>（不可變，永不編輯）

> 這裡存的是我做某件事時所依據的原文，依 vault 硬規則保留不動，供日後稽核「我改了什麼、為什麼」。
> 彙編與取捨判斷寫在 03-wiki 的對應頁，不要在這裡下結論。

## 出處
- **來源**：URL 或取得方式（若是私下提供，寫「誰在什麼場合提供」，不寫聯絡方式）
- **抓取版本**：commit／版次／版本日期
- **授權**：抓取當時的授權條款；是否允許再散布
- **抓取日**：YYYY-MM-DD
- **為何留**：一句話說明未來你會為了什麼回來看它

## 這個資料夾裡有什麼
| 檔 | 是什麼 |
|---|---|
|  |  |
```

## 衍生檔的規則

轉檔出來的東西（PDF／簡報 → Markdown、影片 → 逐字稿）是 **derived，不是原文**，
放在 `02-raw/<主題>/derived-<工具>/`，並在該資料夾的 README 裡寫清楚三件事：

1. **canonical 原檔在哪**（例如 `~/path/to/source/`，大檔不進 git）；
2. **用什麼工具、哪一天轉的**，以及哪些東西轉換後會遺失（版面、圖片、動畫、時間碼）；
3. **重轉指令**——因為規則是「不要編輯衍生檔，原檔更新後重轉覆蓋」。

衍生檔的存在理由是讓 grep、wikilink 與 agent 讀得到內容，不是取代原檔。

## 什麼不該進來

- 任何 secret 的值。原文若含 key，**不要**存進來；只記「這份來源含 key，位置在哪」。
- 個人資料（他人的 email、電話、住址）。需要脈絡時寫角色（「客戶窗口」），不寫身分。
- 超過版本庫負擔的大檔。放外部儲存，這裡只留出處卡與衍生的可搜尋版本。
