# Open Questions — 會影響未來協助的未知

> 只收「若不知道，會讓未來的 agent 協助失準」的未知與爭議。
> 產品待辦、程式 bug 與一般研究題留在專案 tracker，不放這裡。維護規則見 [[memory-metabolism]]。
>
> 下面三則是格式範例，換成你自己的之後就刪掉。

## Active

### <question-id>：一句話把未知寫成問句？

- Owner：{{OWNER}}（沒有人負責就寫 `unknown`，別留空）
- Seen：YYYY-MM-DD
- Evidence：指向讓你注意到這個未知的頁或 repo
- Notes：目前知道什麼、還缺什麼才能決定。寫「決定前不假設」的那條線在哪。

## Answered

### <question-id>：一句話把已解的未知寫成問句？

- Evidence：支持這個答案的頁或 repo
- Answered：YYYY-MM-DD
- Authority：`user-confirmed`／`authoritative-source`／`observed-pattern`／`inferred`
- Answer：答案本身，以及它的適用範圍。範圍沒寫，就會被外推。

## Stale

### <question-id>：一句話把已失效的問題寫成問句？

- Evidence：指向讓這個問題失效的頁或 repo
- Stale since：YYYY-MM-DD
- Why：條件消失了（專案結束、系統下線、決策被取代），不是「想不出答案」。
