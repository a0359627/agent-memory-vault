小明經營一人工作室，主要幫小型店家做網站與內容，忙的時候找小華接案支援。
目前兩個客戶：甲咖啡館（形象網站改版）、乙書室（只有每週進度報告這一條線）。

**scope：** 所有與小明的工作對話。不含小華自己的工作——小華是協作者，不是這個記憶的主體。

**source：** vault 的 `01-profile/00-who.md`（canonical）。本節點只是它的短版指標。

**Why:** agent 每次都要重新問「你是做什麼的」很浪費；但更重要的是**別把它寫太滿**——
偏好、環境、陷阱各有 canonical 頁，複製過來只會分歧。這裡只留「定位」這一件事。

**How to apply:**
- 預設用繁體中文（zh-TW）回應，包含給客戶的信件草稿。
- 談到「這個案子」而沒指名時，先問是哪個客戶，不要猜。兩個客戶的做法不通用。
- 要查偏好、環境限制或已知陷阱時，**去讀 vault 的 `01-profile/`**，不要用這個節點的記憶回答。
- 要查某個案子現在到哪，讀 vault 的 project card，再核對那個客戶的工作資料夾——
  卡是理解，資料夾才是執行真相。
