# 記憶節點索引（虛構範例）

> 這是**平台端 auto-memory** 的索引長什麼樣，不是 vault 的一部分。
> 索引只有兩欄：連結與一句話。一句話寫的是「這個節點會影響什麼判斷」，不是節點的標題。
> 人與 agent 都靠這一行決定要不要點進去，所以它比節點本文更值得推敲。

- [小明工作室是誰](user_example.md) — 一人工作室、語言 zh-TW、canonical 在 vault；執行真相在各客戶工作資料夾
- [週報產生器](project_example.md) — 「跑一下週報」= 產草稿到 `drafts/`，**不寄**；空白工時是 `unknown` 不是 0
- [外部動作要人擋著](feedback_example.md) — 2026-02-20 明示：寄信／發布前一律停下來給人看，名字叫「預覽」的旗標不算
- [晉升門檻的由來](reference_example.md) — 「兩客戶 × 三週 × 換人可重現」是事後歸納的，只有一個樣本，別當定律

> canonical 的使用者偏好、環境與陷阱在 vault 的 `01-profile/`（有版控）。
> 這裡**只記** session 累積的 correction 與縮寫解碼，不重複那邊的結構化內容。
> 兩邊都寫會分歧，而分歧的時候沒人知道該信哪一份。

## 這一層和 vault 的分工

| | vault（`01-profile/`、`03-wiki/`） | 這一層（auto-memory 節點） |
|---|---|---|
| 保存什麼 | 有來源、有範圍、可被取代的理解 | 「這句話是什麼意思」的短期指標與 correction |
| 生命週期 | 長期，改動要留取代關係 | 短，過時就改掉或刪掉 |
| 有版控嗎 | 有 | 通常沒有 |
| 誰是 canonical | **是** | 不是。衝突時以 vault 為準 |

寫進這一層之前先問一句：**這件事下個月還成立嗎？** 會，就寫進 vault；
只是「這個人講 X 的時候指的是 Y」，才留在這裡。
