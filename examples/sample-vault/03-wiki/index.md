# Wiki Index

> 這個 vault 是小明工作室的跨客戶理解 canonical。每個 wiki 頁是一張 card；
> cluster 頁是星狀中心。沒有圖譜檢視器時，從這裡進入整個知識庫。
>
> 根目錄的 `AGENT-RULES.md`／`ROUTING.md` 在這個範例裡刻意沒有放——完整版在 `template/`。

## 依目前目的開始

- **要動某個客戶的案子**：先看 [[cluster-client-work]] 找到對應的 project card，再開客戶的工作資料夾核對現況。
- **要寫這週的客戶報告**：[[skill-weekly-client-report]]，照卡上的觸發條件與完成判準走。
- **客戶又丟了一堆回饋**：[[skill-client-feedback-triage]]（還是草稿，只在一個客戶身上驗證過，用之前先讀限制）。
- **要沉澱新來源**：原文進 `02-raw/`、結論進 `03-wiki/`；分界看 [[ref-client-brief-2026-01]] 這組示範。
- **不確定某件事現在是否還成立**：查 [[open-questions]]，以及該頁 frontmatter 的 `status`。
- **快要踩坑了**：[[03-known-traps]]，四條都附可貼上的修法。

## 主題叢集（star hubs）

- [[cluster-client-work]] — 客戶交付線：兩個客戶、兩個專案、一支已晉升與一支孵化中的 skill。

## 索引頁（分類清單）

- [[projects]] — 所有 project 分叢集列出（含 status）。
- [[skills]] — 所有 skill，分 Active／Draft。
- [[open-questions]] — 會妨礙未來協助的未知／爭議；分 Active、Answered、Stale。

## 個人脈絡

- [[00-who]] — 我是誰、做什麼、canonical 在哪。
- [[01-preferences]] — 怎麼跟我合作；含一條範圍只到單一客戶的 `candidate`。
- [[02-environment]] — 有日期的環境快照與三條硬限制。
- [[03-known-traps]] — 四條被咬出來的陷阱。
