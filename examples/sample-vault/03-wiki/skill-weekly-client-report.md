# weekly-client-report — 每週客戶進度報告

**本體**：[skills-promoted/weekly-client-report/SKILL.md](../skills-promoted/weekly-client-report/SKILL.md)。
本卡只導航；觸發條件、步驟與完成判準讀本體，不在這裡複製一份。

## 什麼情境會觸發它

每週五要給客戶寫進度報告時。它負責到「**產出草稿**」為止——
寄送不歸它管，那是人的決定（[[proj-weekly-report-bot]] 的現行有效段）。

## 2026-02-03 晉升說明

從 `05-skills-drafts/` 晉升為活檔。三個條件同時成立才動的：

1. **兩個以上不同客戶**：甲咖啡館與乙書室。
2. **連續三週格式沒再改**：第三週開始只改內容不改結構，代表流程收斂了。
3. **換一個人也做得出來**：小華照著草稿產出的報告，和小明產的在結構與判準上一致。

依單向晉升路徑，孵化區那份草稿已刪除——**不留兩份會分歧的全文**。
這三個條件是晉升當下事後歸納的，只有一個樣本，因此還沒有升格成通用門檻；
爭議見 [[open-questions]] 的 `draft-promotion-threshold`。

## 它刻意不做的事

- **不寄信。** 見上。
- **不自己解釋 `unknown`。** 工時試算表的空白欄是 `unknown` 不是 0
  （[[03-known-traps]] 第 1 條）；skill 只負責把它標出來並要求人確認。
- **不美化進度。** 沒完成就寫沒完成；「快好了」不是一個狀態。
