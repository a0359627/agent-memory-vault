# Environment — 執行環境的有日期快照

> 2026-02-14 在工作用筆電上唯讀查證（`command -v` ＋ `--version`）。
> 這一頁的價值全在「有日期」三個字：版本會變，快照不會自己更新。
> 安裝或除錯前先在**當前環境**重驗一次，不要拿這張表當現況。

| 工具 | 2026-02-14 觀察 | 備註 |
|---|---|---|
| 作業系統 | macOS（Apple Silicon） | 工作室只有這一台在跑交付 |
| shell | zsh | 腳本一律寫成 `#!/usr/bin/env bash`，不依賴互動式設定 |

| 靜態主機 CLI | 有裝，已登入 | 部署指令直接動到線上站，沒有預覽環境；檔名踩過坑見 [[03-known-traps]] 第 2 條 |
| 試算表匯出 | 手動匯 CSV | 沒有 API；這是 [[03-known-traps]] 第 1 條的來源 |

## 硬限制（這些會反覆咬人）

- **沒有測試環境**。靜態主機只有一個正式站，所以「部署」和「給客戶看」是同一件事；
  要給客戶看草稿只能用本機預覽截圖。**已登入的 CLI 沒有「預覽」這個檔位**——
  任何看起來像預覽的指令，用之前先確認它會不會真的寫出去。
- **客戶端不會操作 git**。交付一律是「我改、我上、客戶驗收」，不能假設客戶會回退版本。
- **沒有自動備份**。上線前的快照是手動複製整個輸出資料夾並標日期。

## 這一頁怎麼維護

換機、換工具鏈、或任何一條硬限制消失時，**新寫一段有日期的快照放在最上面**，
舊快照往下推並標「僅供追溯」。不要就地改版本號——那會讓人以為它一直都是對的。
