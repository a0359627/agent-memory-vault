# diagnosing-bugs — 先建紅燈，再修

難搞 bug 的紀律。只有在有明確理由時才跳過某個階段。

> 按症狀查閱你 vault 的 `01-profile/03-known-traps.md`。0-byte 檔、欄位缺失、輸出長度異常等可用小探針檢查；視覺／語意品質另需適合的驗收，不能用檔案存在或兩秒斷言代替。新知識依 ROUTING 與授權範圍沉澱。

## 階段 1 — 建一個「會 red」的回饋迴圈

**這一步就是整個 skill，其餘都是機械操作。** 只要有一個對「這個 bug」會亮紅燈的緊迴圈，你就找得到原因；沒有的話，盯著 code 看再久也沒用。把不成比例的力氣花在這裡。**積極、有創意、不放棄。**

### 怎麼建（大致照這個順序試）
1. **對輸出下斷言的一行 script**：`test -s out.bin || echo FAIL`（抓 0-byte 產物）；用該格式的檢查工具驗長度／欄位／結構；取幾個樣本點驗某個維度沒被歸零。
2. **CLI 跑 fixture**，把 stdout／輸出檔跟「已知 good」的快照 diff。
3. **重放捕獲的 payload**：把真實的外部 API 請求存到磁碟，單獨重放那條 code path。
4. **差分迴圈**：同一輸入分別過「舊參數 vs 新參數」「舊 commit vs 新 commit」，diff 兩邊輸出。
5. **二分**：如果 bug 出現在兩個已知狀態之間（某次 commit／某次換素材／某次升版），自動化「切到狀態 X→檢查→重複」，用 `git bisect run`。
6. **非確定性 bug**：目標不是乾淨重現，是**提高重現率**——把觸發迴圈跑 100 次、加壓、縮小時間窗，直到高到可 debug。

### 收緊迴圈
把迴圈當產品：能更快嗎（跳過無關 init）、訊號能更利嗎（斷言打在**確切症狀**上，不是「沒 crash」）、能更確定嗎（釘住時間、固定亂數種子、隔離檔案系統）。2 秒的確定迴圈是 debug 超能力；30 秒的 flaky 迴圈幾乎等於沒有。

### 完成判準——一個會 red 的緊迴圈
能講出**一條指令**（script 路徑／一次 CLI 呼叫／一行斷言），你**已經至少跑過一次**（貼出呼叫與輸出），且它：
- [ ] **會 red**：真的走到出錯的 code path，斷言打在**你描述的確切症狀**上——能為這個 bug 亮紅、修好後轉綠。
- [ ] **確定**：每次同樣判決（flaky bug：釘住的高重現率）。
- [ ] **快**：秒級，不是分鐘級。

先讀足以定位接合面和副作用的 code／log，再建立可安全執行的重現。若無法安全重現，記錄限制，改用既有事故證據或隔離副本；不要為了製造紅燈碰 production。

## 階段 2 — 重現 + 最小化
跑迴圈，看它亮紅。確認亮的是**使用者描述的那個**失敗，不是旁邊另一個長得像的（錯的 bug＝錯的修法）。然後把重現場景縮到**還會亮紅的最小狀態**：一次砍一個輸入／呼叫者／設定／步驟，每砍一次重跑。留下的每一項都是承重的——砍掉任一個就轉綠為止。

## 階段 3 — 提出假設
先提出足以區分原因的假設，優先測試最有辨識力的一個；複雜或證據衝突的問題再擴充候選。每個假設要**可證偽**：講出它的預測——「如果是 X 造成的，那改 Y 會讓 bug 消失／改 Z 會更嚴重。」講不出預測的是感覺，丟掉或磨利。需要使用者持有的關鍵資訊時才提問；可自行驗證的假設直接查證。

## 階段 4 — 加裝儀器
每個探針對應階段 3 的一個預測。**一次只動一個變數。** 優先用 debugger／REPL 斷點（一個斷點勝十行 log），其次打在能區分假設的邊界上的 log。**每條 debug log 加唯一前綴** `[DEBUG-a4f2]`，最後一個 grep 清乾淨。效能問題別用 log：先立基準量測（計時、profiler），再二分。

## 階段 5 — 修 + 回歸測試
**先寫回歸測試再修**——前提是有**正確的接縫**（測試能重現 bug 在呼叫點的真實樣態）。把最小重現變成一個會失敗的測試→看它失敗→套修正→看它通過→再對原始（未最小化）場景重跑階段 1 的迴圈。若沒有正確接縫，**這件事本身就是發現**：架構讓這個 bug 鎖不住，記下來。

## 階段 6 — 收尾 + 事後
交付前必做：原始重現不再重現、回歸測試通過（或記錄「無接縫」）、所有 `[DEBUG-...]` 清掉（grep 前綴）、丟棄的 prototype 刪掉、把**猜對的那個假設**寫進 commit 訊息。

**然後問：什麼本來能擋掉這個 bug？** 如果答案是一個可重複的沉默失敗——**依你 vault 的 `ROUTING.md` 與本次授權，把「症狀＋適用版本＋檢查＋修法」保存進 `01-profile/03-known-traps.md`**，讓它從此不再咬人。這才是這支 skill 最大的複利。
